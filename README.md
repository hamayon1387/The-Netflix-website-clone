# Netflix Website

A Netflix-inspired website built with **HTML and CSS**, featuring a modern streaming-platform design and responsive layout.

## Features

* 🎬 Netflix-inspired user interface
* 📱 Responsive design
* 🖼️ Movie and TV show sections
* 🎨 Modern and clean layout
* 🌐 Built from scratch with HTML and CSS

## Technologies Used

* HTML
* CSS

## Purpose

This project was created to practice and improve **HTML and CSS** skills by recreating the look and feel of a modern streaming platform.
